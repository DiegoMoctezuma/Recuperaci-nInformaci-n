# Textos para generar la narración en la web de ElevenLabs

En el plan gratuito, las voces mexicanas de la biblioteca solo se pueden usar desde la web (elevenlabs.io), no desde la API.
Pasos: elige la voz, selecciona el modelo **Eleven v3**, pega cada texto, genera, descarga el MP3 y guárdalo en `video/audio/` con el nombre indicado.
Las etiquetas entre corchetes dirigen la emoción; no se leen en voz alta.

Voces mexicanas de mujer sugeridas (búscalas por nombre en la biblioteca): **Gabriela - Warm, Rich and Balanced** (madura, narrativa), **Camila - Inviting, Rich and Warm** (joven, narrativa), **Isabel - Neutral, Balanced and Calm** (didáctica).

